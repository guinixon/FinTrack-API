# FinTrack API 💰

Backend de um aplicativo financeiro desenvolvido com **Python** e **FastAPI**, focado no gerenciamento financeiro pessoal.

## 🚀 Objetivo

Este projeto tem como objetivo fornecer uma API robusta para um sistema financeiro, permitindo controle de:

- Receitas
- Despesas
- Categorias
- Saldo
- Histórico financeiro
- Relatórios futuros

## 🛠️ Tecnologias utilizadas

- Python
- FastAPI
- Uvicorn
- Pydantic

pip install -r requirements.txt

# iniciar servidor
uvicorn app.main:app --reload
